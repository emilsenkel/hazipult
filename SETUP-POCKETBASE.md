## HáziPult - Self-Hosted Setup with PocketBase (Mac Mini)

This guide lets your 13-year-old use HáziPult from **anywhere** with real cloud saving and photo attachments. Everything runs on your Mac Mini.

### Step 1: Run the automated script

On your Mac Mini, run:

```bash
curl -fsSL https://raw.githubusercontent.com/emilsenkel/hazipult/main/setup-macmini.sh -o setup-macmini.sh && chmod +x setup-macmini.sh && ./setup-macmini.sh
```

### Step 2: Follow the next steps

After the script finishes, open this file for the remaining actions (create admin account, database collection with photo support, and Cloudflare Tunnel):

**→ [NEXT-STEPS.md](NEXT-STEPS.md)**
